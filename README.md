# Daily Tracker – Vibe Coding Experiment with Codex

A small React and TypeScript app for tracking daily activities, moods, goals and patterns over time.

## About the Experiment

This project was built entirely with **OpenAI Codex**. The application code, structure and styling were generated by the coding agent based on natural-language requirements and iterative feedback.

The goal was to explore what happens when an AI coding agent is given responsibility for building a complete frontend application instead of working alongside a developer as a coding assistant.

## What I Learned

Vibe Coding is a fundamentally different way of working.

Instead of translating my ideas directly into code, I have to translate them into natural language first. The agent then interprets that language and translates it into code.

That additional layer can introduce misunderstandings, particularly with UX, responsive behaviour, visual design and code structure.

The experiment showed me that **AI coding agents can be useful development tools, but I would currently not trust one with full responsibility for a production application without substantial human oversight and intervention.**

The generated code in this repository is intentionally left in its original state to document the result of the experiment.

A second implementation with another AI coding agent may follow.
